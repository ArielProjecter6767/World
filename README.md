# Aether AI — starter

Adaptive AI assistant starter built with FastAPI, MongoDB Atlas, and a responsive animated orb UI.

## Included
- Register/login/logout using username or email and a password hash (Argon2).
- Signed, HTTP-only session cookie.
- MongoDB-backed users and chat history.
- Responsive interface and pointer-reactive animated orb.
- Optional Groq chat adapter activated by `GROQ_API_KEY`.
- Render Blueprint (`render.yaml`).

## Local run
1. Install Python 3.12.
2. Create a virtual environment: `python -m venv .venv`
3. Activate it (Windows: `.venv\\Scripts\\activate`; macOS/Linux: `source .venv/bin/activate`).
4. Install: `pip install -r requirements.txt`
5. Copy `.env.example` to `.env`, then set `SECRET_KEY` and `MONGODB_URI`.
6. Run: `uvicorn main:app --reload`
7. Open `http://127.0.0.1:8000`.

## MongoDB Atlas
Create a database user and cluster. In Network Access, allow the Render service's outbound connections (for initial testing you can use `0.0.0.0/0`, with a strong DB password; tighten access when practical). Copy the Atlas connection string into `MONGODB_URI`, URL-encoding special characters in the password.

## Render deployment
1. Push this folder to a new GitHub repository.
2. In Render, create a **Blueprint** from that repository, or create a Python Web Service.
3. Set `MONGODB_URI` in Render environment variables. `SECRET_KEY` can be generated by the Blueprint.
4. Optional: set `GROQ_API_KEY` to activate real text responses.
5. Deploy and test `/api/health`, then register a test account.

## API routes
- `GET /api/health`
- `POST /api/auth/register` — `{ "username": "...", "email": "...", "password": "..." }`
- `POST /api/auth/login` — `{ "login": "nickname-or-email", "password": "..." }`
- `POST /api/auth/logout`
- `GET /api/auth/me`
- `GET /api/chat/history`
- `POST /api/chat` — `{ "message": "..." }`
